# On-Device Cybersecurity and Digital Safety AI

P3 prototype for local SMS spam, phishing URL, and network-flow classification with an optional local Llama 3.2 1B Instruct advisory component.

See [Technical Documentation](docs/technical_documentation.md) for the inspected architecture, datasets, preprocessing, saved evaluation results, limitations, privacy behavior, deployment status, and run instructions.

The repository's detector artifacts, datasets, and Llama model files are excluded by `.gitignore`; they must be provisioned or generated locally. The documented project state is a Streamlit prototype. ARM performance and mobile deployment have not been measured or established.
